# Reference-to-Figure templates

- <code>style-profile.schema.json</code>: JSON Schema for a portable reference-derived design profile.
- <code>style-profile.example.json</code>: valid example profile with explicitly estimated color values.
- <code>generate_figure.py</code>: editable Matplotlib starter for user-supplied CSV line, scatter, and bar plots.
- <code>project-README.md</code>: README copied into a newly scaffolded figure project.

The AI inspects the user's reference material and writes the profile. These templates do not perform visual recognition on their own.
