# RS encoder concept example

\`rs_encoder_concept.svg\` is an original, editable conceptual illustration of a systematic
LFSR-style Reed–Solomon encoder. It is **not** an implementation-specific architecture and is
not derived from a particular RTL design.

Before using a diagram for a paper, replace the generic feedback/tap representation with the
actual generator polynomial, GF multipliers, XOR equations, register ordering, parallelism, and
input/output protocol from the design being documented.
