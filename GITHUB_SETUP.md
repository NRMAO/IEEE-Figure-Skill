Clone the repository:

```bash
git clone https://github.com/NRMAO/IEEE-Figure-Skill.git
cd IEEE-Figure-Skill
```

The repository contains the reusable Agent Skill, reference design rules, editable SVG/Mermaid/Python
sources, and original examples. Uploaded source papers are intentionally excluded. Do not commit
access tokens, credentials, or copyrighted paper figures.
